Applications HA UGSo ​

Ce dépôt commun constitue le point de publication central pour toutes les applications Home Assistant de UGSo Software : applications MQTT, Grafik Visual Studio, « Blocks for HA » et projets futurs. Chaque application dispose de son propre sous-répertoire, de sa propre version et de sa propre documentation. L'URL du dépôt existant reste inchangée.

Applications HA UGSo et autres projets ​

ProjetDocumentation
Logic Studio0.1.6 : première version publique de test ; plans à blocs, import HA et sortie YAML/JavaScript. Éditeur allemand, documentation DE/EN/FR.
Gestion des utilisateurs du tableau de bord0.1.4 : Utilisateurs présentés sous forme de colonnes avec cases à cocher, affectation groupée ou individuelle, interface disponible en DE/EN/FR et sauvegarde du tableau de bord avant l'enregistrement.

Dépôt d'add-ons commun ​

Les projets MQTT sont désormais principalement distribués via un dépôt d'add-ons commun pour Home Assistant. Il suffit d'ajouter une seule URL de dépôt dans Home Assistant ; les différents projets apparaîtront ensuite individuellement dans la boutique d'add-ons (Add-on Store).

URL du dépôt pour Home Assistant :

text
https://github.com/rockbaer2007/ugso-ha-mqtt-addons
1

Modules complémentaires inclus :

  • FRITZ!Box to MQTT

  • Heizöl to MQTT

  • Parcel to MQTT (développement arrêté)

  • Client MQTT : permet de transmettre des appareils et des valeurs sélectionnés depuis Home Assistant vers ioBroker ou un broker MQTT externe. 0.1.16 ajoute la prise en charge des changements d'état en temps réel (avec un mécanisme de secours par interrogation), des statuts détaillés, un nettoyage confirmé des anciens sujets « retain » (persistants), des commandes de contrôle supplémentaires, la sauvegarde des paramètres au format JSON et la gestion de certificats TLS personnalisés. Les paramètres existants restent valides ; les données « retain » ne sont pas supprimées automatiquement. Le broker HA déjà en place demeure inchangé.

  • Ouvrir le dépôt commun de modules complémentaires sur GitHub

Les anciens dépôts individuels restent accessibles en tant qu'archives historiques et renvoient vers ce dépôt commun.

FRITZ!Box to MQTT ​

FRITZ!Box to MQTT

Une application pour Home Assistant qui expose les données de la FRITZ!Box sous forme d'entités via la découverte MQTT (MQTT Discovery). Elle combine le protocole TR-064, des requêtes sur l'interface web/Lua de la FRITZ!Box et la surveillance des appels en temps réel.

  • Ouvrir la documentation de FRITZ!Box-to-MQTT
  • Ouvrir le dépôt individuel archivé sur GitHub

Heizöl to MQTT ​

Heizöl to MQTT

Une application pour Home Assistant qui met à disposition les prix du fioul domestique (provenant d'Esyoil et Heizöl24) sous forme d'entités via la découverte MQTT (MQTT Discovery). Actuellement, les meilleurs prix ainsi que jusqu'à six offres de fournisseurs par source et par quantité sont publiés.

  • Ouvrir la documentation de Heizöl-to-MQTT
  • Ouvrir le dépôt archivé sur GitHub
  • Adapté de : TA2k/ioBroker.heizoel

Parcel to MQTT ​

Parcel to MQTT

Développement arrêté : Parcel Tracker est un projet bien plus abouti. Par conséquent, nous cessons le développement de notre propre solution. Nous vous invitons à découvrir Parcel Tracker, par SoerenKaiser99. La documentation existante est conservée à titre d'archive.

Une application pour Home Assistant qui intègre le suivi de colis sous forme d'entités via « MQTT Discovery ». La version actuelle prend en charge les listes de colis issues d'un compte DHL, les numéros de suivi DHL (optionnels) ainsi que le suivi des colis Hermes.
