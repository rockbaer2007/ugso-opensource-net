Formatage automatique ​

Avec auto_format: true, la carte utilise les paramètres de formatage de Home Assistant, tels que l'unité et la précision.

yaml
type: custom:flex-table-card
title: Temperatur
entities:
  include: sensor.outdoor_sensor_air_temperature
auto_format: true
columns:
  - name: Temperatur
    data: state

Préfixe, suffixe et alignement ​

yaml
type: custom:flex-table-card
title: Verbrauch
entities:
  include: sensor.*_energy*
sort_by: power-
columns:
  - name: Name
    data: name
  - name: Leistung
    id: power
    data: power_consumption
    modify: parseFloat(x)
    suffix: " W"
    align: right
  - name: Energie
    data: state
    modify: parseFloat(x).toFixed(1)
    suffix: " kWh"
    align: right

Assistants de formatage ​

fmt utilise des formateurs intégrés.

FormatFonction
numberConvertir une valeur en nombre
durationAfficher des secondes sous forme de durée
duration_hAfficher une durée plus longue incluant les jours
iconAfficher une icône MDI
full_datetimeConvertir une date textuelle en horodatage
hours_passedHeures écoulées depuis une date
hours_mins_passedHeures et minutes écoulées
time_passedTemps écoulé dans un format approximatif lisible
yaml
columns:
  - name: Batterie
    data: state
    fmt: number
    suffix: "%"
    align: right

Modification ​

modify est du code JavaScript qui reçoit la valeur lue dans la cellule sous le nom x.

yaml
columns:
  - name: Richtung
    data: sendungsinfo.sendungsrichtung
    modify: x == "ANKOMMEND" ? "zu mir" : "von mir"

Sécurité

modify exécute du code JavaScript. Ne l'utilisez qu'avec des données provenant de sources en lesquelles vous avez confiance.
