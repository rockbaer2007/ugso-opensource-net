Installation ​

Installation via HACS ​

  1. Ouvrir Home Assistant.
  2. Ouvrir HACS.
  3. Accéder à Integrationen. 4. Ouvrir + Explore & Download Repos.
  4. Rechercher Zendure.
  5. Télécharger Zendure Home Assistant Integration.
  6. Actualiser le navigateur si Home Assistant n'affiche pas encore directement l'intégration.
  7. Ouvrir Einstellungen -> Geräte & Dienste -> Integration hinzufügen.
  8. Rechercher Zendure et lancer la configuration.

Lien direct :

Ajouter l'intégration Zendure dans Home Assistant

Jeton (token) de l'application Zendure ​

L'intégration utilise un jeton provenant de l'application Zendure. Ce jeton doit être issu du compte principal sur lequel les appareils sont enregistrés.

Mise à niveau depuis des versions antérieures

Pour les installations anciennes comportant un second compte ou utilisant une ancienne méthode de connexion, l'ancienne configuration doit être supprimée puis recréée. L'intégration actuelle repose sur un système de jetons (tokens).

La fenêtre de saisie du jeton est documentée dans le wiki d'origine, capture d'écran à l'appui :

Capture d'écran du jeton dans le wiki d'origine

Options dans la fenêtre de configuration ​

OptionSignification
Zendure TokenJeton (token) provenant de l'application Zendure
P1 Sensor für Smart MatchingCapteur de consommation domestique : valeur positive en cas de consommation, négative en cas d'injection sur le réseau
MQTT-Kommunikation loggenEnregistre les échanges MQTT dans les journaux (logs) de Home Assistant (si le mode débogage est activé)
Lokales MQTT verwendenOuvre une seconde fenêtre pour la saisie des données MQTT locales
MQTT-Benutzer automatisch verwaltenTente de gérer automatiquement les identifiants d'accès MQTT
WLAN SSIDNom du réseau Wi-Fi pour la reconfiguration des appareils
Wifi PasswortMot de passe du réseau Wi-Fi pour la reconfiguration des appareils

Après la configuration ​

Une fois la configuration effectuée avec succès, les appareils Zendure et leurs entités apparaissent dans Home Assistant. Si vous possédez plusieurs appareils, il est recommandé de configurer correctement le groupe de protection (Fuse Group) afin que les fonctionnalités de « Smart-Matching » (correspondance intelligente) et de limitation de puissance fonctionnent de manière optimale.
