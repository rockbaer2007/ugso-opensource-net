HADashHome Assistant Dashboard Toolkit

Extraire et sauvegarder des tableaux de bord ainsi que des vues individuelles à partir de fichiers YAML, JSON et de sauvegardes non chiffrées de Home Assistant.

Premiers pas
GitHub
🧩

Sauvegarder des vues individuelles

Exportation au format TXT, YAML ou sous forme de tableau de bord complet et autonome.

🗄️

Tableaux de bord issus de sauvegardes

Traiter les données JSON provenant de sauvegardes Home Assistant non chiffrées et du dossier `.storage`.

🔄

Conversion de JSON vers YAML

Importer des configurations de tableaux de bord et les enregistrer au format YAML.

💾

Application portable

Aucune installation classique n'est requise.

Pourquoi HADash a été créé ​

HADash est né de la volonté de pouvoir sauvegarder séparément des vues individuelles de tableaux de bord Home Assistant.

De plus, l'objectif était de permettre l'extraction de tableaux de bord complets à partir d'anciennes sauvegardes Home Assistant non chiffrées, ou depuis des fichiers JSON situés dans le dossier .storage, afin de les enregistrer à nouveau au format YAML.

Aperçu

HADash est encore en cours de développement. Vos retours, signalements de bugs et suggestions d'amélioration sont les bienvenus.
