Getting Started ​

Requirements ​

  • Windows 10 or Windows 11
  • matching .NET Desktop Runtime
  • dashboard file or unencrypted backup data

Installation ​

  1. Open the HADash releases.
  2. Download the current portable ZIP package.
  3. Extract it into its own folder.
  4. Start HADash.exe.

Supported Formats ​

  • .dash
  • .yaml
  • .yml
  • .json
  • .txt
  • additional files through All files (*.*)
