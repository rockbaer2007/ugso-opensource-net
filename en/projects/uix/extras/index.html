Adapted from the canonical English UIX documentation by Lint-Free-Technology/uix, CC BY 4.0. Source: master / 9.0.0, revision f63ebbd, reviewed 5 November 2026. Requires Home Assistant 2026.11.0 or later. Markup adapted for this site; the original documentation remains authoritative.

UI eXtension provides for additional settings to control the integration or Home Assistant Frontend.

  • UIX actions
  • Custom sidebar panels
  • Element configuration defaults
  • Frontend states throttling
  • Dialog styling delay
  • Disable hash template variable and updates
  • Disable icon styling patching
  • Disable entity picture image overrides
  • Always patch ha-card (experimental)
  • Style frame panels (experimental)
