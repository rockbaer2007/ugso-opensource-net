Home Assistant Connection ​

The Card Editor can receive a Home Assistant URL and access token from Atlas Administration. The token is not written permanently into the editor; it is only used as a session handoff.

The editor currently supports:

  • connection through the Home Assistant WebSocket API
  • loading entities through get_states
  • local cache for entities and entity domains
  • synchronization status below the connection state
