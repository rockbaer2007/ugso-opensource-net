Data sources ​

Data from entities ​

The value at data determines what is displayed in a column.

yaml
columns:
  - name: Name
    data: name
  - name: Entity-ID
    data: entity_id
  - name: Status
    data: state
  - name: Icon
    data: icon

Commonly used selectors:

selectorMeaning
namefriendly name
object_idEntity ID without domain
entity_idcomplete entity ID
statecurrent status
iconEntity icon
areaRange if available
floorfloor if available
deviceDevice name if available
platformDomain, for example sensor

Nested attributes ​

Nested objects are read using dot notation.

yaml
columns:
  - name: Status
    data: sendungsdetails.sendungsverlauf.status
  - name: Nummer
    data: sendungsdetails.sendungsnummern.sendungsnummer

Multiple values in one column ​

Multiple selectors can be combined with comma.

yaml
columns:
  - name: Raum und Geraet
    data: area,device
    multi_delimiter: " / "

Static data ​

static_data can be used for tables without home assistant entities.

yaml
type: custom:flex-table-card
title: AQI-Stufen
entities: []
columns:
  - name: AQI
    data: aqi.level
  - name: Kategorie
    data: aqi.category
  - name: Hinweis
    data: aqi.concerns
static_data:
  aqi:
    - level: 0-50
      category: Gut
      concerns: Kaum Risiko.
    - level: 51-100
      category: Moderat
      concerns: Fuer empfindliche Personen moeglichweise relevant.
