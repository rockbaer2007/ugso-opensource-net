Requirements ​

Each external HACS documentation page should identify:

  • Project name
  • Original repository
  • Original documentation
  • Translated revision or version
  • License and attribution
  • A clear note that the original documentation remains authoritative
  • Status: current, review required or outdated

  • Lovelace cards: HA Cards
  • Custom integrations: HA Integrations
