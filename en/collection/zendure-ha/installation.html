Installation ​

Installation via HACS ​

  1. Open Home Assistant.
  2. Open HACS.
  3. Go to Integrationen.
  4. Open + Explore & Download Repos.
  5. Search for Zendure.
  6. Download Zendure Home Assistant Integration.
  7. Reload the browser if Home Assistant does not yet display the integration directly.
  8. Open Einstellungen -> Geräte & Dienste -> Integration hinzufügen.
  9. Search for Zendure and start the setup.

Direct link:

Add Zendure integration to Home Assistant

Zendure app token ​

The integration uses a token from the Zendure app. This token should come from the main account that the devices are registered to.

Upgrade from older versions

For older installations with a second account or old login, the old configuration must be removed and set up again. The current integration is token-based.

The token dialog is documented with a screenshot in the original wiki:

Token screenshot in original wiki

Options in the setup dialog ​

optionMeaning
Zendure TokenTokens from the Zendure app
P1 Sensor für Smart MatchingSensor for house consumption: positive for consumption, negative for feed-in
MQTT-Kommunikation loggenwrites MQTT communication to the HA log when debug logging is active
Lokales MQTT verwendenopens a second dialog for local MQTT data
MQTT-Benutzer automatisch verwaltentries to manage MQTT credentials automatically
WLAN SSIDWLAN name for the device change
Wifi PasswortWiFi password for device switching

After setup ​

After successful setup, Zendure devices and their entities appear in Home Assistant. If there are several devices, the Fuse Group should then be set correctly so that smart matching and power limitations work sensibly.
