UGSo HA Apps ​

The shared repository is the central publishing location for all UGSo Software Home Assistant apps: MQTT apps, Grafik Visual Studio, Blocks for HA and future projects. Each app has its own subdirectory, version and documentation. The existing repository URL is retained.

UGSo HA Apps and other projects ​

ProjectDocumentation
Dashboard User Manager0.1.4: user checkbox columns, bulk/individual assignments, automatic DE/EN/FR interface and dashboard backup before saving.
CallMeBot WhatsappExperimental HA App 0.1.4: recipient profiles, WhatsApp texts via MQTT, DE/EN/FR and matching Blockly blocks.
CallMeBot SignalExperimental HA app 0.1.0: Signal texts, phone/UUID profiles, separate MQTT namespace and Blockly profile selection in DE/EN/FR.
Blocks for HAExperimental HA app 0.1.3: visual Blocks for native automations, YAML import/export and extensible branches; editor through HA ingress.
Grafik Visual StudioGraphical editor and runtime for HA visualizations.

These projects live in the same repository as the MQTT apps below.

Additional frontend extensions ​

ProjectDocumentation
Sidebar Colors0.1.0: per-entry colors and opacity in the native HA sidebar editor. DE/EN/FR, synchronized per user; separate GitHub repository, for HACS and Marketplace. Not a Supervisor app.
Sidebar Manager0.1.7: colors/opacity, folders with icons, shared ordering, expanded-only separators and custom links in a new tab or iframe. DE/EN/FR, GitHub, HACS-compatible frontend plugin.
Automation Status Card0.1.3: automatic list, configurable rows/scrolling, optional controls, checkbox selection and run/trace diagnostics. DE/EN/FR; verified on HA 2026.10.4.

Shared Add-on Repository ​

The MQTT projects are now primarily provided through a shared Home Assistant add-on repository. Home Assistant only needs one repository URL; after adding it, the individual projects appear separately in the add-on store.

Repository URL for Home Assistant:

text
https://github.com/rockbaer2007/ugso-ha-mqtt-addons
1

Included add-ons:

  • FRITZ!Box to MQTT

  • Heizöl to MQTT

  • Parcel to MQTT (development discontinued)

  • MQTT-Client: send selected Home Assistant devices and values to ioBroker or an external MQTT broker. 0.1.16 adds live state changes with polling fallback, detailed status, confirmed cleanup of recorded obsolete retained topics, additional commands, JSON settings backup and custom TLS certificates. Existing settings remain valid; retained data is never deleted automatically. The existing HA broker stays in place.

  • Open the shared add-on repository on GitHub

The former single-project repositories remain visible as archived history and point to this shared repository.

FRITZ!Box to MQTT ​

FRITZ!Box to MQTT

A Home Assistant app that publishes FRITZ!Box data as MQTT Discovery entities. It combines TR-064, FRITZ!Box web/Lua queries and the live call monitor.

  • Open the FRITZ!Box to MQTT documentation
  • Open the archived single-project repository on GitHub

Heizöl to MQTT ​

Heizöl to MQTT

A Home Assistant app that publishes heating-oil prices from Esyoil and Heizöl24 as MQTT Discovery entities. It currently publishes best prices and up to six provider offers per source and amount.

  • Open the Heizöl to MQTT documentation
  • Open the archived single-project repository on GitHub
  • Adapted from: TA2k/ioBroker.heizoel

Parcel to MQTT ​

Parcel to MQTT

Development discontinued: Parcel Tracker is already much further along, so we are discontinuing development of our package. We recommend taking a look at Parcel Tracker by SoerenKaiser99. Our existing documentation remains available as an archive.

A Home Assistant app that publishes parcel tracking data as MQTT Discovery entities. The current version uses DHL account parcel lists, optional DHL tracking numbers and Hermes parcel tracking.

  • Open the Parcel to MQTT documentation
  • Open the package in the shared add-on repository
  • Open the archived single-project repository on GitHub
  • Adapted from: TA2k/ioBroker.parcel
